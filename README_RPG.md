# 雨夜跑团 · OperitRPG

基于 [Operit](https://github.com/AAswordman/Operit) 的 Android 单人文字跑团原型。使用原创短模组《雨夜旧码头》、本地 d100 规则、独立战役存档和可选云端 AI 主持。

首版 0.1.0 已发布，进入手机体验与验收阶段。支持 Android 8.0 以上 ARM64 手机。它保留 Operit 的通用能力，但首次启动直接进入跑团页，无需启用 Root、Shizuku、通知或自动化权限来跑团。

## 安装与更新

从 [Releases](https://github.com/CGM2026/OperitRPG/releases) 下载 `operit-rpg-版本.apk`，直接在手机上安装。首次安装时 Android 可能要求允许浏览器安装应用。

后续在跑团设置或关于页点“检查新版本”，阅读版本说明后点“下载并安装”。下载后检查哈希、包名、版本及已安装应用签名，再交给 Android 安装器确认。首次从应用内更新时，按系统提示允许“雨夜跑团”安装更新。固定包名与独立长期签名使后续版本可覆盖更新，保留本地存档。更新需要手机能连接 GitHub。

## 第一次游玩

1. 新建战役，使用预设角色林舟，也可以修改名字。
2. 选择“离线演示”先验收界面和规则，或进入模型设置添加自己的服务配置后选择真实模型。
3. 阅读开场，用中文输入行动，例如“去办公室”“查看便条”“去档案室”“查找货号登记”。
4. 随时打开人物、线索、地点抽屉。每次行动自动保存。

离线演示是明确选择的固定脚本，不代表真实 AI 质量。网络出错不会自动切换到演示模式。真实模型的服务费用由所选供应商按账号计费，APK 不附带任何 API Key。

## 范围

一个内置模组，三个 NPC，四个地点，观察/说服/攀爬检定，生命与绷带，线索来源记录，单一时间线，完整存档导入导出。百分骰规则为本项目原创简化规则，不是完整 CoC 或 D&D。

AI 只识别行动与生成叙述，程序执行检定和状态变化。已提交的骰点不因断线重掷；恢复未完成叙述需要用户主动点击。备份是包含完整模组状态的主持档案，导入创建新战役并要求重新选择模型。
