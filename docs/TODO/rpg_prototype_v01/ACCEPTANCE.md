# 手机验收指引

## 安装

在手机浏览器打开 [雨夜跑团 Releases](https://github.com/CGM2026/OperitRPG/releases)，下载该版本的 APK。首次按 Android 提示允许浏览器安装应用，再点击安装。应用名为“雨夜跑团”，与原版 Operit 独立安装。

新应用有独立的数据空间，需要在其模型设置中配置自己的模型。先选“离线演示”即可检查界面和游戏流程，不需要 API Key。

## 先看界面与基本操作

1. 首次进入后新建战役，名字可以修改。页面应采用黑体、暖白背景、低饱和绿色，正文两侧有明显留白。
2. 进入游玩页，查看地点、时间和生命。人物、线索、地点应从当前页面展开，关闭后回到原阅读位置。
3. 输入几行文字并打开键盘，检查按钮没有被遮挡，长内容可以滚动。转动屏幕后不应重复提交行动。
4. 查看初始人物：生命 6、绷带 1；满血时不能使用绷带。初始没有已发现线索。

## 完成一次离线演示

以下是用于验证完整流程的明确路线，包含模组解法。如果希望先自行探索，可跳过这一节。

依次输入并等待每轮完成：

1. 去办公室
2. 查看便条
3. 进入档案室
4. 查看货号登记
5. 返回办公室
6. 返回院门
7. 去码头
8. 请船工帮忙救阿远

账簿检定使用程序的真实随机骰点：成功时最终时间为 8，失败时为 9；两条路线都能完成救援。检定失败会多花时间，但仍能读出关键线索。最终生命 6、绷带 1、获得两条线索。

打开检定详情，检查骰点与阈值一致。线索详情应能跳回发现时的记录。结束后可回顾或询问规则，不能继续推进世界动作。

离线演示的主持使用固定脚本与关键词，不代表云端模型的自然语言能力。输入未覆盖的表达时，不会凭空执行新的游戏动作。

## 保存与恢复

完成任意行动后退出，再重新打开应用，地点、时间、人物和历史应保持。不要通过卸载来测试关闭应用，卸载会清除其私有数据。

在战役设置导出 `.rpgsave.zip`。再次导入后应出现一场独立战役，原战役保留；新战役需要重新选择模型。导入前应能看到标题与角色名。任意损坏的存档必须报告错误，不能留下半个战役。

真实模型运行时，可在请求期间切换网络或强制停止应用后重开。程序不应自动发起新模型请求。若检定已经保存，只允许继续完成叙述，骰点与资源不应再次改变；若行动尚未执行，应可重试或取消。

## 手机更新

进入战役设置或关于页，点击“检查新版”。

- 当前已是最新版：显示明确提示，不下载。
- 有新版：显示版本说明和大小，只有点击“下载并安装”才下载。
- 下载后校验失败：显示错误，不交给安装器。
- 首次更新：Android 可能要求允许“雨夜跑团”安装应用；授权后返回，继续安装。
- 取消系统安装：旧版仍可使用，可以再次安装更新。
- 成功覆盖安装：重新打开后，原有战役仍在。

首次发布时尚无更高版本，所以只能验收“已是最新版”。完整覆盖升级需要至少两版使用相同签名、逐增 versionCode 的 APK；发布后的验证记录会说明是否已完成该项。

## 真实模型验收

在模型设置配置你自己的服务，再在战役中选择。以一场新战役测试至少 30 次交互，其中有效行动推进情节，闲聊、规则问答和回顾不推进游戏时间。重点观察：模型是否听懂行动、是否替你做决定、是否和骰点矛盾、NPC 是否提前知道尚未发现的事实。

当前不附带测试账号或 Key。缺少真实模型和手机的验证不会被自动测试代替。请记录手机型号、Android 版本、应用版本、模型名、具体操作和实际表现；反馈时无需提供 API Key。
