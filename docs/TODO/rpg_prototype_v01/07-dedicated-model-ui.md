# 二十面骰专用界面

0.2.0 保留跑团的 28dp 留白、黑体、暖白纸面与莫兰迪配色。应用名改为二十面骰，内置《雨夜旧码头》的百分骰规则不变。

模型管理使用独立 RpgModelConfigStore，不依赖 Operit 通用设置。列表呈现名称、协议、完整地址、模型名与遮罩 Key。新增/编辑必须明确选择协议，不自动修改地址；不支持的旧配置保持可见，提示原因，用户选择新协议并保存前不转换。删除需明确确认，保留战役。

新建和战役设置可进入模型管理并返回，SaveableStateHolder 保留新建表单；无战役时也有设置页，提供模型配置和应用更新入口。没有自动试连。Key 不写入 Compose SavedState，只有明确点击显示才明文显示。读取失败显示具体的本机配置读取问题与手动重读入口，不将损坏配置当成空配置覆盖。

新配置从 https:// 开始填写。保存 HTTP 地址须确认“API Key 和内容可能被网络读取”；协议改变不修改地址。校验拒绝 URL 内账号、查询参数与片段，仅保留旧的末尾 # 标记兼容。

公开入口 DiceModelSettingsScreen(onBack)，内部内容 RpgModelSettingsScreen。模型选择器新增 selectable 字段，旧不支持配置可展示原因并保持不可选。

矢量图标资源 rpg_d20_icon.xml 使用灰鼠尾草绿三角网格，不改变任何检定或规则含义。

Android Compose 测试新增显式协议选择、旧 OAuth 再配置、HTTP 保存前确认三项。设备测试尚未执行；静态 git diff --check 通过，APK 编译由集成 CI 统一检查。
