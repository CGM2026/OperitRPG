# 跑团原型 v0.1

原项目是通用手机 Agent。本次新增独立跑团入口，沿用模型配置，独立游戏状态、规则、存档和回合生命周期。原型使用原创《雨夜旧码头》与简化 d100 规则。

用户已启动实施，授权 GPT 6.1 sol / medium 下属 Agent 按模块开发，并授权公开仓库及应用更新发布。此次要求覆盖此前交接文件中的单 Agent、禁止远端发布限制。页面两侧留白稍加宽，实施值先取 28dp。

分工：rpg_core 负责纯 Kotlin 核心与测试；rpg_ui 负责 Compose 界面和导航；release_update 负责手机更新与发布工作流；主 Agent 负责 Room、模型桥接、备份、集成与验收。

## 任务

- T00 固定基线、构建环境与可复现依赖
- T01—T02 核心协议、规则与模组
- T03—T04 持久化、回合幂等与恢复
- T05 原生页面与导航
- T06 Operit 模型连接
- T07 完整存档导入导出
- T08 自动测试与真实环境验收
- T09 固定包名/签名、GitHub Release、手机手动检查和确认更新

完成情况以验收报告与真实日志为准。真实云端模型测试须有可用的授权配置；不会读取其它项目的 API Key。没有设备的项目保留待验证，不用静态检查代替实机验证。

## 集成约定

核心以 [CORE-CONTRACT.md](CORE-CONTRACT.md) 为准。为使单事务保存和恢复更直接，Room v1 用一条 campaign aggregate JSON 加可查询元数据保存战役；唯一输入、回合序号与事件序号在同一数据库事务内验证。这是相对最初五表设计的实现收敛，保留事件重放与不可重复结算约束，未来数据库迁移必须保留已有存档。
