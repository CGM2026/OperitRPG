# D20 App v0.5：跑团专用客户端

目标：把 App 收敛成"只负责跑团"的干净客户端。模组与人物卡由外部 agent 按模组规范制作，App 只导入、运行、存档、导出。

## 已拍板的产品决定

- 首页只有一张战役列表，没有底部标签栏。右上角：搜索、设置（模组库、模型、外观、数据导出都收在设置里）。右下角 `+`：导入模组 → 选人物卡 → 新建战役。
- 战役分组由用户自定义。长按战役：置顶、重命名、移动到分组、隐藏、导出、删除。长按分组：重命名、新建分组、删除分组（组内战役回到"未分组"）。
- 对话页：主持叙述为阅读式正文（无气泡，衬线字体）；玩家发言靠右小气泡；掷骰结果为一行小标签，点开看加值与过程；章节存档点显示为细分隔线。
- 人物卡：点右上角角色头像拉出抽屉（资源池、状态、物品、能力），平时不占屏幕。
- 输入框左侧 `+` 收纳行动菜单与桌面指令（停、降档、升档等），不在界面上摆按钮。
- 外观：纸色浅底，跟随系统切深色。
- 文案规范：界面不放解释性段落；功能首次使用时提示一次；按钮 1–3 个字的动词短语。
- 头像：见 `02-avatars.md`。人物 = 动物笔触 × 配色；战役 = 意象笔触 × 配色。同名确定性生成，用户可手动换。
- 不兼容 0.3 存档；数据库按全新应用建。
- App 内不再提供模组生成/草稿功能。
