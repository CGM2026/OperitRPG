# 二十面骰 0.2.0

“雨夜跑团”改名为“二十面骰”，成为专用的 Android 单人文字跑团应用。移除通用手机 Agent、终端、浏览器、本地推理引擎、语音、虚拟形象和插件系统，保留战役、角色、掷骰、线索、物品、记录、备份和手机内更新。使用黑体、低饱和配色和 28dp 页面留白。

已有 0.1.0 的用户可以直接检查新版并覆盖安装。应用身份、发布签名、存档数据库和备份格式保持不变；请勿先卸载旧版。旧战役和已经结算的骰点继续保留。内置模组仍为《雨夜旧码头》，规则仍是原有简化百分骰规则。

模型设置改为专用页面，支持 OpenAI Chat、OpenAI Responses、Anthropic 和 Gemini 的文字接口，也可以选择离线演示。普通兼容 API 配置继续读取；旧 OAuth 登录、多密钥轮换、自定义请求头和参数等高级配置不再执行，原记录保留并显示需要重新配置。不会自动切换接口或模型。

在手机“设置 → 检查新版”中查看说明、确认下载和安装。首次可能需要允许此应用安装更新。更新时核对下载大小、SHA-256、应用身份、版本和签名证书，后续版本继续使用同一发布证书。

本版交付会附带规则、模型协议、旧备份和更新校验测试，以及 Android 模拟器上的同签名覆盖升级结果。升级测试使用按 0.1.0 结构生成的数据样本，安装的是本次正式签名候选包；个人手机上的旧数据、厂商安装器及真实模型长团体验仍需用户验收。
