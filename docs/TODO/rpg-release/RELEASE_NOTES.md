# 二十面骰 0.3.0 测试版

新增独立长团引擎：可导入数据模组 ZIP、阅读与绑定 Markdown/TXT 资料、显式调用所选模型整理可编辑草稿；通过校验与确认后激活模组。提供《雪线驿站失踪案》《赤岭边境巡护》两个原创示例，各含 6 地点、12 NPC、3 章节目标。

Agent 可以查规则、读局部世界、检索记事、查询 NPC 知情范围，再提出行动。程序负责验证条件、掷骰、原子提交事件和状态，模型负责理解与叙述。每轮模型与工具有次数上限；失败可明确恢复，不会自动重试或切换模型。现阶段规则适配器为原创通用百分骰，不是 CoC 或 D&D 的完整实现。

长团另用 rpg-agent.db，事件与回合分页保存，NPC、事实、知识关系单独记录。公开记事支持来源查看和更正；模组及规则锁定版本。格式 2 完整备份包含依赖模组、规则、状态和历史，恢复为新战役并要求重新绑定本机模型。

原《雨夜旧码头》战役、格式 1 备份和模型配置继续保留。应用标识、永久签名证书保持一致，Android versionCode 升至 3。**请直接覆盖安装，不要卸载旧版。** 界面继续使用黑体、莫兰迪色系及 28dp 左右留白。

这是供用户验收的预发布版本。真实模型的长团表现与资料整理质量由用户验收，本次没有调用收费模型。可明确选择“离线流程演示”验证操作与存档流程；它不代表真实模型能力。未配置真实模型时不会假装联网。

在手机打开本页下载 APK 即可安装。稳定版的“检查新版”继续保留，此测试版不替换稳定版发布通道，因此 0.2 的稳定更新按钮不会提示此预发布包；后续正式版本仍可在手机内检查、下载并安装。同一证书核验继续有效。

完整检查结果和限制见发布附件测试报告。模型文本仍需人工验收；尚不支持 PDF/OCR、多玩家同步、自定义脚本、任意规则插件或语音。
