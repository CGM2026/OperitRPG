# 雨夜跑团首版

内置《雨夜旧码头》短篇跑团：使用预设角色并修改名字，输入行动，探索地点、收集线索、查看物品与生命状态，完成不同结局。需要确认的行动先确认再结算，模型请求失败可重试；已结算的动作不会因叙述重试再次掷骰。

可选择离线演示模型直接体验。演示使用预设规则与回应；使用真实模型时，请自行配置供应商、模型与 API 密钥，模型费用由对应供应商收取。网络失败不会自动切换到演示模型。

支持本地保存战役、导入导出备份，并从手机内点击“检查新版”，查看说明、确认下载后安装。首次更新可能需要在系统设置中允许“雨夜跑团”安装应用，再返回继续。

这是用于体验和验收的首版。自动化规则与更新校验测试已纳入构建，真实手机的安装、权限返回、旋转屏幕、进程终止恢复与覆盖升级仍需实际验证。
