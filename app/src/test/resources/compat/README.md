# 0.1.0 备份格式固定样本

`v0.1.0.rpgsave.zip` 由与已发布 `rpg-v0.1.0` 逐文件相同的 rpg-core 主源码及 RpgBackupService 导出。生成前通过 git diff 确认两者未改变。它不是从用户手机采集的存档。

样本包含四个已完成行动、两个线索、一次固定骰点 30 的账簿检定，位于档案室，时间为 4。模型标识与请求记录按旧版导出逻辑清除为 UNBOUND。

LegacyBackupCompatibilityTest 直接读取固定二进制样本，检查导入后的骰点、线索、资源及事件，并再次导出读取。测试自身不生成输入存档，避免把格式改变同时写进测试输入。
